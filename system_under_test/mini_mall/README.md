# 被测系统：迷你商城（Mini Mall）

> 这是一个**故意埋了缺陷**的 Web 应用，用作自动化测试的靶场。
> 技术栈：Flask + SQLite（单文件 `app.py`）。

## 启动

```bash
cd system_under_test/mini_mall
python app.py          # 需要先 pip install flask
```

启动后访问 http://127.0.0.1:5001

> ⚠️ **每次启动都会重建数据库**（`init_db()` 里是 DROP TABLE + 重建），
> 也就是：测试环境每次都是干净的（这正好符合"测试数据要自包含"的原则）。

## 故意埋的缺陷（BUG1~BUG8）

| 编号 | 缺陷 | 对应需求条目 |
|---|---|---|
| BUG1 | 手机号完全不校验（含字母/位数错/空 都能注册） | R1 |
| BUG2 | 密码只查长度，不查是否含字母+数字 | R2 |
| BUG3 | 注册成功后**不自动登录**（停在登录页） | R5 |
| BUG4 | 登录失败提示区分"账号不存在"/"密码错误"（可枚举账号） | L2 |
| BUG5 | 购物车修改数量后，小计与总额**不重算** | C2 |
| BUG6a | 库存不足**不拦截**下单（超卖） | C5 |
| BUG6b | 下单后**不扣减**库存 | C6 |
| BUG7 | 数量 0 也能下单成功（0 元订单） | C7 |
| BUG8 | 购物车页缺少返回商品列表的入口（可用性） | C3 |
